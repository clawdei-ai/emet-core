# /core — Reference Implementation

This directory will contain the reference implementation of the EMET protocol.

## Planned Components

- **Claim Engine** — Create, sign, and validate claims
- **Verification Pipeline** — Cross-model consensus mechanism
- **Reputation System** — Stake-weighted trust scoring
- **Decay Manager** — Confidence decay and truth versioning
- **Bootstrap Module** — Genesis grants and proof-of-learning for new agents

## Technology Stack (TBD)

- Language: TypeScript / Rust
- Cryptography: CRYSTALS-Dilithium (post-quantum), BLS12-381
- Storage: Content-addressed (IPFS / custom)
- Network: P2P gossip protocol
